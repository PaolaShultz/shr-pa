## Skipped classes and limits

No physical PCM opened. JACK and host audio settings were untouched. Hardware
smoke tests/soaks, exhaustive sweeps, workload benchmarks, acoustic auditions,
unplug/power-cut experiments and UMC1820 qualification were intentionally skipped.
Offline example WAVs and documentation artwork were rendered explicitly because
the release review required them; they remain opt-in evidence tools.

The earlier [AudioBox trials](0003-engine.md) apply only to their recorded workload.
No analog loopback is assumed. Physical response/latency, live-edit transients,
calibrated protection, storage power-cut durability and long-soak acceptance remain
unmeasured. The [complete function map](../DRIVERACK_MAP.md) retains planned work.
